# Routine

루틴이 조용히 사라지지 않게, 오래 안 한 것을 계속 눈앞에 보여 주는 아이폰용 웹앱.

- 매일 / 일주일에 몇 번 / 며칠마다(병원 등) 세 종류 루틴
- 기록: 한 달 달력 하나에 그날 한 루틴을 이모지로 (이모지가 많으면 그 주 칸이 높아짐), 루틴별 보기, 날짜 누르면 그날 체크/해제
- 루틴 숨기기(👁): 지우지 않고 오늘 화면·위젯에서만 빼기
- 루틴 순서는 고정(설정에서 ▲▼로 변경), 오래 안 한 루틴은 빨간색(사라지는 중)으로 표시
- 아침처럼 메뉴를 고르는 루틴은 먹은 것을 기록하고 "지난번과 같음"으로 한 번에 기록
- Scriptable 잠금화면 위젯 + 정한 시각 알림 (`scriptable/Routine.js`)
- 데이터는 폰의 이 앱 안(localStorage)에만 저장. 설정 → 백업으로 파일 저장

버전 규칙: 고칠 때마다 `app.js`의 `APP_VERSION`과 `sw.js`의 `CACHE`를 올린다. `scriptable/Routine.js`의 `// 버전:` 줄은 그 스크립트를 고쳤을 때만 올린다(올리면 폰에서 다시 복사해야 함).
